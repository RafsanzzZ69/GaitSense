# Contributing

Request collaborator access, clone with your own GitHub authentication, branch from main and submit focused pull requests. Atlas access and research inputs require separate authorization.

Read README.md, docs/CURRENT_STATE.md and applicable AGENTS.md before edits. Use the frontend lockfile and backend constraints. Run relevant checks and report untested behavior. Never use the shared database for disposable tests; migrations require confirmed targets and backup.

Keep secrets, participant material and generated binaries out of Git. Use synthetic fixtures. Update requirement evidence without marking untested behavior complete. Project licensing remains undecided; preserve third-party notices.
